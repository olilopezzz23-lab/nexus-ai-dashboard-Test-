[![Live Demo](https://img.shields.io/badge/Demo-Live%20Preview-06b6d4?style=for-the-badge&logo=vercel)](https://github.com/olilopezzz23-lab/nexus-ai-dashboard)

[![Frontend](https://img.shields.io/badge/Stack-TailwindCSS%20|%20Vanilla%20JS%20|%20Chart.js-3b82f6?style=for-the-badge)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A modern, responsive, high-performance Single Page Application (SPA) dashboard engineered for AI workload management, API token metrics, team collaboration, and financial analytics.

Built with a glassmorphism design language, micro-interactions, dynamic multi-chart visualization, and fully localized reactive components.

---

## ✨ Features

- **📊 Real-time Metric Visualizations:** Interactive Chart.js charts with gradient fills, custom tooltips, and time-frame filtering (7D, 30D, 90D).
- **🌗 Native Theme Switching:** Smooth Dark / Light mode toggle powered by Tailwind CSS utility classes and CSS variables.
- **⚡ Reactive SPA Navigation:** Instant client-side tab switching across Overview, Analytics, Models, Infrastructure, and Settings without page reloads.
- **🎨 Glassmorphism & Modern UI:** Blur backdrops, crisp borders, custom scrollbars, and high-DPI Lucide iconography.
- **📱 Fully Responsive:** Adaptive layouts optimized across mobile devices, tablets, laptops, and ultra-wide displays.
- **🛠 Zero-dependency Build:** Runs straight out of the box in any modern browser without heavy npm build pipelines.

## 💻 Quick Start / Local Setup

No Node.js or build steps required. Simply clone the repository and open `index.html` in your browser:

```bash
# 1. Clone the repository
git clone https://github.com/olilopezzz23-lab/nexus-ai-dashboard.git

# 2. Navigate to project folder
cd nexus-ai-dashboard

# 3. Open in browser (Windows PowerShell)
Start-Process index.html
```

Or serve with any static server:
```bash
# Using Python
python -m http.server 3000

# Using npx serve
npx serve .
```
